# Security Policy

## Supported Versions

We currently support and provide security updates for the following versions:

| Version | Supported          |
| ------- | ------------------ |
| main    | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within eBPFDivert, please do **not** open a public issue. Instead, please report it privately to the maintainers.

You can report vulnerabilities by:
- Emailing the maintainer (see commit history for contact info).
- Using GitHub's private vulnerability reporting feature (if enabled).

We will acknowledge your report within 48 hours and provide a timeline for a fix and disclosure.
